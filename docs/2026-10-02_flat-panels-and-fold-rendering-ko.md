# 평평한 패널과 기존 접힘을 분리하는 튜닝

사용자 요구: 기존 접힘은 추가로 접힐 수 있게 유지하고, 주변 패널의 작은 휨은 억제한다. 화면은 물리 격자보다 촘촘하게 표시하되 물리 정점을 따르며, 접힘 경계를 둥글게 지우지 않는다.

## 구현 범위

- 물리: 기존 비선형 굽힘 모델의 **미항복·작은 곡률 구간**을 조정한다. 접촉하지 않은 정점을 고정하거나 평면으로 투영하지 않는다. 비접촉 패널에도 주변에서 하중이 전달될 수 있다.
- 평면 강화 후보 `S32`: `scale=32, knee=0.4, end=14.75`. 기존 `S16,0.75,14.75`보다 아주 작은 휨의 초기 저항이 2배이다. 모든 곡률에서 2배라는 뜻은 아니다. 항복 곡률15 이전에 기존 큰 곡률 법칙으로 연결되며, 이미 소성 이력이 있는 힌지의 힘·감쇠·영구 접힘 법칙은 유지한다.
- 렌더: 접힘 보존 전환을 기존60–100도에서25–45도로 앞당겼다. 그보다 완만한 면은 기존 PN 삼각형 곡면으로 보간하고, 뚜렷한 접힘은 양쪽 면의 법선을 분리한다. 외피 두께 방향의 연속성은 유지한다.
- 물리1,402정점/2,800삼각형, 표시37,368삼각형/112,104면별 정점이다. 표시 정점 수에는 UV·법선 경계 중복이 포함된다. 두께4mm, 물리 격자와 접촉 형상은 변경하지 않았다.
- 별도 USD `assets/demo_scene_robotiq_board4_flat_panels.usda`로 기존 장면을 보존했다. 합성 USD 비교에서 렌더 임계값 두 개만 변경된 것을 검증했다.

표시 보간은 물리 격자에 없는 주름이나 더 정확한 접촉을 복원하지는 않는다. 물리 결과의 해상도 한계와 표시의 삼각형 각짐은 구분해야 한다.

## 비교 방법과 현재 결과

같은4mm 격자, ROM12/VBD12, GPU의 같은 소성 이력 갱신을 사용했다. `outputs/flat_panels` 아래 모든 시도와 전체16초 궤적을 별도로 보존했다. 다른 GPU 작업이 함께 실행 중이므로 실행시간은 참고값이다.

국부 평탄도는 원래 같은 패널에 속한 정점 한 이웃 범위에 평면을 맞춘 RMS이다. 접힘 이웃과 접촉 영역도 포함하는 비가중 통계이며, "외력이 없는 면적 비율"로 해석하면 안 된다. 회전·이동과 패널의 작은 굽힘을 구분하기 위한 기하 지표이다.

| 설정 | 집기 전 윗면 처짐5초 | 압착12초 국부 RMS 중앙값 | 최종16초 국부 RMS 중앙값 | 16초 계산 관측 |
|---|---:|---:|---:|---:|
| 같은 조건 S16 재측정 | 0.369mm | 0.803mm | 0.797mm | 116.76초 |
| S48 | 0.177mm | 0.623mm | 1.532mm | 76.82초 |
| S32 + 접힘 손상 강화 | 0.217mm | 0.808mm | 0.686mm | 138.30초 |
| S32, 기존 접힘 재료 유지 | 0.214mm | 0.506mm | 0.730mm | 115.34초 |
| S32, 국부 colored VBD | 0.288mm | 0.776mm | 1.458mm | 97.09초 |

S48은 낙하 후 주름 확산과 평탄도 악화로 제외했다. 손상 강화(`damageRate=8`, `residualStiffness=0.08`)는 압착 중 조기 테이블 복귀와 파지 실패로 제외했다. S32는 집기 전 처짐과 압착 시 중앙값이 개선됐지만 모든 평탄도 지표가 개선된 것은 아니다. 최종0.5mm 이내 이웃 비율은 기준44.4%, S32 43.7%이며, 최종 최대 속도는78.3→189.3mm/s로 악화됐다. 따라서 기존 기본 물리 설정으로 승격하지 않는다.

연속 파지 검사도 기준3/5, S32 2/5로 완전 통과하지 못했다. 양쪽 접촉력과 접촉부 이동을 계속 검사했으며, 단순히 들어 올렸다는 이유로 무미끄럼을 주장하지 않는다. S32는 놓기 명령 전 테이블 복귀는 없었다(최소131.9mm 여유). 수치 보정 방식 비교 결과와 최종 프리뷰 선택은 아래에 기록한다.

S32의 국부 보정을 Jacobi에서 colored VBD로 바꾸면 파지는4/5로 회복됐으나, 최종 소성 힌지가2,864개로 늘고 국부 평탄도와 진동이 악화됐다(최종 최대231.4mm/s). 작은 휨을 억제하는 것만으로 큰 압착 뒤의 접힘 확산을 해결하지 못했다. 다섯 전체16초 실험을 마쳤으며, 새로운 물리 설정은 모두 승격하지 않았다.

## 선택한 GUI 프리뷰와 미완료 범위

```bash
bash scripts/live_flat_panels.sh
```

위 명령은 **기존 adaptive_jacobi24/S16 물리 설정 + 새 접힘 보존 표시**를 연다. `Play / Resume`는 새 물리 계산, `Recorded replay`는 기존 검증 궤적에 새 표시 보간을 적용한 재생이다. S32 물리 후보가 적용된 것으로 오해하지 않도록 물리 설정을 명시한다.

물리 후보는 각 `run_config.json`과 궤적으로 재현·비교할 수 있지만 GUI 기본 선택에는 넣지 않았다. 사용자 요구 중 큰 압착과 낙하 후에도 비접힘 영역이 평평하게 남도록 하는 **물리 거동은 미완료**이다. 이번 결과는 전역 초기 강성만 높이거나 모든 기존 접힘을 더 약하게 하는 단순 튜닝으로 해결됐다는 근거가 없다. 다음 물리 변경에서는 작은 소성 이력만으로 초기 강화가 즉시 사라지는 전환, 접힘 주변 하중 전달, 접촉 수렴을 구분해 검증해야 한다. 이 원인이 확정됐다는 뜻은 아니다.

## 렌더링과 검사

같은 기준 물리 궤적의9초에서는 표시 정점 차이가0, 큰 접힘이 생긴12초에서는 최대2.19mm였다. 물리 정점은 변경되지 않았다. [같은 정점의 표시 비교](../outputs/flat_panels/render_review/render_comparison.png).

50도로 접힌 두 평면을 촘촘하게 샘플링하는 회귀 검사를 추가했다. 새 설정은 두 평면을 보존하지만 기존 설정은 접힘 주변을 부풀리는 것을 재현했다. 평면 정확성, 원래 정점 통과, 완만한 공유 경계 연속성, 두께 외피 연속성, 강체변환, 접힘 전환의 연속성을 함께 검사한다.

굽힘6개, 곡면10개, 접힘 재료5개로 총21개 검사가 통과했다. 새 미소 굽힘 힘과 수치 에너지 미분의 일치, 양의 근사 접선, 기존 소성 힌지 법칙 유지, 손상 이력과 비음수 에너지 소산을 확인했다. 완료 궤적의 유한 값·소성 이력·손상 범위·단조 소산도 통과했다. 이는 실물 골판지 보정이나 모든 동작의 품질 통과를 의미하지 않는다.
