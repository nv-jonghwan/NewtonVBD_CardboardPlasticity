# 기울어진 그리퍼로 놓은 뒤 옆으로 넘어지는 동작

후속 사용자 검토에서 놓기 전 미끄러짐이 확인됐다. 아래15/15는 연속 파지를 검사하지 않았으므로 파지 합격을 의미하지 않는다. [연속 파지 재검토](2026-10-01_tilted-grip-retention-ko.md).

사용자가 최신 작은 변형 보강 후보에서 그리퍼를 비스듬하게 두어 박스가 떨어진 후 옆으로 쓰러지게 해 달라고 요청했다. 기존 작은 변형 S16/.3/5.9, 집기500/상승300/압착4000, 접촉 용량512, 메시·재료·충돌·solver 예산을 유지하고 손목 목표 자세만 조정한다.

## 구현

`cardboard:graspTiltDegrees`, `cardboard:liftTiltDegrees`에 월드 XYZ 각도를 도 단위로 저장한다. 기본값은 모두0으로 원래 동작을 보존한다. 접근 구간에서 초기 집기 각도로, 상승 구간에서 최종 기울기로 기존 부드러운 이동 보간을 따라 전환한다. 회전 중심은 이동된 박스 중심이며 원래 손목 위치/회전과 그리퍼 개폐 깊이 보정을 함께 회전시킨다. 따라서 손목만 회전해서 집는 점이 큰 원을 그리는 문제를 피한다. 로봇 IK 경로를 미리 계산하며 원래 그리퍼 관절/접촉으로 박스를 움직인다. 박스 좌표나 속도에 별도 회전/충격을 강제로 주지 않는다.

회전 중심의 tool-frame 좌표·거리 보존, 복합 회전의 정규성, 원래0도 경로의 정확한 보존을 검사했다. 기존 검사 포함61개 회귀 검사 통과.

## 첫 접근 후보 제외

월드X10도로 기울여 접근하고 상승하면서30도까지 기울이는 첫 후보는4.85초에 집기 전 소성 힌지1개가 발생해 기존 검증이 중단했다. 그리퍼가 닫히기 전 모서리에 접촉하는 것이 원치 않는 초기 변형을 만들 수 있어 제외했다. 판정 기준을 완화하지 않고 초기 집기는 수직으로 보존한 후보로 변경했다.

## 판정 방법

양쪽 접촉, 정상 상승·압착·분리, 모든 관절 연결과 유한 상태를 기존 기준으로 확인한다. `review_tilted_drop.py`는 전체 물리 메시의 최적 강체 정렬 각도와 원래 각 판면의 최종 높이·접촉 근처 정점 수를 함께 기록한다. 전체 박스가60도 이상 기울고, 원래 옆면 중심이 바닥면 중심보다 낮으며, 해당 옆면에 가장 낮은 높이3mm 이내 정점이 있으면 옆으로 넘어짐을 관측한 것으로 판정한다. 단순 윗면 구김만 옆넘어짐으로 세지 않는다. 이 판정은 완전 정착이나 실제 로봇의 가반하중 검증이 아니다.

## 수직 집기 → 상승 중30도 후보 결과

16초 전체 시험에서 옆넘어짐 판정3개와 기존 동작검사15개를 모두 통과했다. 집기 전 소성0, 양측 상승 접촉 유지, 최저점 기준 상승147.8mm, 압착 종료 간격166.43mm, 접촉 용량 초과0건. 최대 관절 앵커 오차1.988mm로2mm 기준 이내지만 여유가 작으므로 반복성까지 보장하지 않는다.

그리퍼는 상승 종료부터30도를 유지했고, 전체 박스의 최적 강체 정렬 기울기는 압착 종료35.42도,13초53.51도,15초59.10도,16초88.62도였다.16초에는 원래 -Y 옆면의625정점 중618개가 최저점3mm 이내에 있고, 해당 면 중심은z=0.656m로 원래 바닥면 중심0.753m보다 낮았다. 최종 최대 속도0으로 기존 sleep 기준에 따라 멈췄다. 윗면만 접힌 상태가 아니라 박스 전체가 옆면을 대고 놓인 것을 확인했다.

원래 압착과 다른 접촉 방향 때문에 주름 배치와 압착 간격은 달라진다. 최종 소성 힌지2574개이며 재료 계수는 바꾸지 않았다. 이번 단일 관측의 전체 실행 시간177.92초는 모드 횟수와 GPU 부하가 달라 기존 속도와 직접 비교하지 않는다. 옆넘어짐 관측은 반복 성공률이나 전체 재료 모델의 검증 완료를 의미하지 않는다.

장면: `assets/demo_scene_robotiq_board10_tilted_release.usda`. 원본을 상속한5필드 overlay이며 시험 장면의 모든 속성·관계와 일치함을 확인했다. 원본 기본 장면은 유지한다.
