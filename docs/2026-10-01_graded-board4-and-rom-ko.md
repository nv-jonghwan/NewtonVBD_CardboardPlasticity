# 4mm 비균일 격자와 ROM/VBD 교대 실험

사용자가 요청한 면별 격자 감소, 4mm 두께, 반복 방법 재설계와 ROM/VBD 교대를 함께 실험했다. 이전 형상·집기 기준은 측정 지표로 남기고, 새 후보의 전체 궤적 수집을 막는 조건으로 사용하지 않았다. 최종 성능·형상 비교는 `outputs/graded_board4/review/summary.json`과 이 문서 하단에 기록한다. 기본 GUI 장면은 아직 교체하지 않았다.

## 무엇을 교대로 푸는가

한 서브스텝 안에서 **ROM → VBD → ROM → VBD**를 실행한다. 두 단계는 동일한 현재 위치, 접촉, 관성 목표와 소성 이력을 사용한다. 각 단계마다 물리 시간이 흐르는 것이 아니라, 같은 시간 스텝의 해를 번갈아 보정한다. 마지막 반복은 VBD이다. 이 실험에서 VBD 차례는 전체 쉘을 순회하며, 접촉 주변만 푸는 국부 VBD는 아직 구현하지 않았다.

ROM은 `Δx = U Δz`, `(Uᵀ D U) Δz = Uᵀ f`를 푼다. `D`는 VBD의 양의 정점별 3×3 Hessian 블록이다. 이는 **투영된 준뉴턴 보정**이며, 이웃 정점 사이의 결합까지 포함하는 `Uᵀ H U`의 정확한 Galerkin 축소나 다중격자 구현은 아니다. 48회는 물리적으로 필수인 숫자가 아니라 반복 예산이다. 국소 Gauss–Seidel 방식에서는 넓은 판면에 걸친 오차의 해소가 느릴 수 있다. [VBD 원 논문](https://ankachan.github.io/Projects/VertexBlockDescent/index.html).

현재 기저는 4mm 축소 격자 VBD48 궤적에서 만든 8개 방향이다. 이동 3개와 중심 이동을 뺀 위치 증분 POD 5개이며, 학습 증분 에너지의 88.77%를 담는다. 이 비율은 힘·형상 정확도나 새 동작의 일반화 정확도가 아니다. 학습에 사용한 동일 동작으로 테스트한 **초기 타당성 실험**이다. 기저 생성 전에 16초 기준 궤적 계산 비용이 필요했고, 실행 중에는 저장된 시간별 위치를 재생하지 않는다.

소변형 S16 보강과 이미 항복한 힌지의 재질 분기를 ROM 힘/Hessian 계산에도 연결했다. 이전 실험 코드의 기본 굽힘만 사용하는 경로와 혼용하지 않는다. 소성 이력 갱신은 원래처럼 서브스텝 뒤에 수행한다.

## 두 실행 방식

- 기본 guarded: 표현 오차와 새 힘 잔차를 검사하고 실패하면 같은 차례에 전체 VBD로 복귀한다. 두 차례 전체 힘 평가와 CUDA 조건부 자식 그래프가 필요하다.
- `--rom-fast`: 두 번째 전체 힘 평가는 생략한다. 유한값과 충돌 절단을 검사하고, 거절한 보정은 건너뛴 뒤 다음 예정된 VBD에서 처리한다. 조건부 자식 그래프 없이 GPU 마스크 커널로 적용한다. 단조 에너지 감소나 guarded 방식의 정확도 보장은 주장하지 않는다.

실험에서는 표현 허용값을 1로 두어 사실상 표현 범위 검사를 완화했다. 0.1mm ROM 보정 상한과 원래 충돌 절단은 유지했다. `--iterations 24`는 쉘뿐 아니라 강체 반복 예산도 24로 바꾸므로, 48회 기준보다 빨라졌다는 사실만으로 ROM의 효과라고 볼 수 없다. 같은 24회 순수 VBD 대조군을 따로 실행했다.

## 격자와 두께

| 항목 | 4mm 정규 기준 | 4mm 비균일 후보 |
|---|---:|---:|
| 물리 정점 | 3,458 | 1,402 |
| 물리 삼각형 | 6,912 | 2,800 |
| 힌지 | 10,368 | 4,200 |
| 축 분할 | 24/24/24 | 18/14/14 |

접촉 높이와 판 중앙 부근을 더 촘촘하게 배치하고, 모든 면이 공통 축 좌표를 공유해 모서리의 불일치 정점을 피했다. 동적인 적응 재격자는 아니다. 연결성·외향 법선·면적·체적·밀도 분포 테스트를 추가했다. 물리 삼각형 수는 약 59.5% 감소했다. 두 후보 모두 표시 삼각형도 173,760개에서 37,368개로 줄이고 UV와 물리 바인딩을 새로 만들었다.

10mm에서 4mm로 바꾸면서 면밀도와 면내 강성은 0.4배, 두께 세제곱 굽힘 계수는 0.064배로 변한다. 항복 및 소변형 곡률 경계는 같은 변형률을 유지하도록 2.5배로 옮겼다. 단순히 두께 이름만 변경하지 않았다. 외부 치수를 유지하도록 중립면 치수도 조정했다. 따라서 이전 10mm 결과와 동일한 접힘 모양을 기대하는 실험은 아니다.

정규/비균일 VBD48은 모두 16초를 완주하고 집기·상승·압착·낙하를 수행했으나, 16초 시점 최대 속도가 각각 0.0573/0.9471m/s로 남았다. 두 경우 모두 기존 안착 지표는 실패했다. 축소 격자의 낙하 후 진동과 형상 변화는 별도 개선 대상이다. 두 기준 실행은 서로 다른 GPU에서 수행했으므로 전체 시간 231.52/210.88초를 공정한 격자 속도 향상률로 사용하지 않는다.

## CUDA Graph의 실제 범위

`Simulation._integrate()`는 접촉 탐색, 강체/쉘 반복, 내부 감쇠, 소성 갱신을 포함해 Graph로 캡처된다. ROM 투영·작은 연립방정식·변위 반영도 GPU에서 실행하며, 교대마다 CPU로 좌표를 왕복하지 않는다. 첫 프레임 준비와 active/supported/sleep 모드별 그래프 구성에는 호스트 작업이 있다.

`Simulation.advance()`의 동작 명령, FK, sleep 판단, 진단값 읽기와 GUI 전달은 CPU가 관여한다. 따라서 **핵심 적분은 GPU Graph이지만 애플리케이션 전체가 fully GPU인 것은 아니다.**

`outputs/graded_board4/profile/`의 현재 재질/S16, 축소 격자, 초기 1초 계측:

- 워밍업·계측 삽입 프레임을 제외한 57프레임의 평균 실행 235.83ms, Graph GPU 시간 233.50ms, 차이 2.33ms. 이 구간은 약 99.01%가 GPU Graph 시간이다. 전체 동작의 비율로 일반화하지 않는다.
- 상세 샘플은 16서브스텝 × 48반복 × 8색상으로 쉘 탄성 커널만 프레임당 6,144회 실행한다. 전체 `wp.launch` 호출은 46,689회이다. 접촉·강체·충돌 절단 등이 추가된다.
- 진단에서는 프레임당 GPU 배열을 17회, 152,400바이트 읽었다. 해당 읽기 시간에는 선행 GPU 계산 대기가 섞이므로 순수 전송 비용으로 해석하지 않는다.
- 따라서 폴리곤 2,800개라는 숫자만으로 계산 시간을 예측할 수 없다. CUDA Graph는 호출 비용을 줄여도 그 안의 많은 커널 계산과 순차 색상 의존성을 없애지는 않는다.

## 새 설계의 방향과 구현 경계

이전 구현 제약을 벗어나 설계한다면, 판별 회전·큰 굽힘을 표현하는 다중 영역 ROM과 접촉/주름 주변의 국부 자유도를 결합하는 것이 타당하다. ROM 보정을 해도 기존 VBD의 세부 변형을 지우지 않도록 현재 위치에 증분만 더한다. 접촉/새 주름 영역은 GPU 마스크로 확장하고, 접촉 밖 판면의 내부 힘은 대표 요소 적분으로 줄이는 방향이다.

이 방향의 근거는 접촉 주변만 full space로 활성화하는 [Subspace Condensation](https://www.tkim.graphics/CONDENSE/)과, 내부 힘 적분 요소 수를 줄이는 [Optimizing Cubature](https://www.cs.cornell.edu/~djames/papers/cubature08.pdf)이다. 논문의 특정 속도 수치를 이 종이박스 장면에 적용할 수는 없다. 여기서 구현한 교대 프로토타입은 **아직 전체 요소의 힘을 평가**하므로, 이 구체적인 국부/대표 요소 설계와는 구분해야 한다.

완전히 GPU에 상주시키려면 제어·sleep 및 수렴 판단도 GPU 배열/리덕션으로 옮기고, CPU에는 낮은 빈도의 표시용 상태만 전달해야 한다. 현재 초기 구간 측정만 보면 그 작업 단독의 속도 이득보다 반복 내부의 계산 축소가 우선이다.

## 재실행

```bash
OPENBLAS_NUM_THREADS=1 ./scripts/python.sh scripts/benchmark_vbd_optimized.py \
  --scene assets/demo_scene_robotiq_board4_graded.usda \
  --output outputs/graded_board4/my_alternating_run --schedule guarded --device cuda:1 \
  --small-bend-scale 16 --small-bend-knee .75 --small-bend-end 14.75 \
  --rom-basis outputs/graded_board4/basis8.npz --rom-tolerance 1 \
  --rom-full-every 2 --rom-start --rom-fast --iterations 24 \
  --exploratory --panel-diagnostics
```

출력은 아직 존재하지 않는 새 디렉터리를 지정한다.

## 최종 관측 결과

모두 물리 시간 16초를 새로 계산했다. 아래 시간은 초기 모델 생성 시간을 제외하지만 프레임별 진단·그래프 구성 비용을 포함한다. GPU 공유 부하와 모드/접촉 경로 차이가 있으므로 확정 가속비로 해석하지 않는다.

| 실행 | 쉘 반복 구성 | 계산 시간 | 들어 올린 높이 | 최종 최대 속도 |
|---|---|---:|---:|---:|
| fine48 | 정규 격자 VBD48 | 231.52초 | 141.45mm | 57.27mm/s |
| graded48 | 비균일 격자 VBD48 | 210.88초 | 151.41mm | 947.06mm/s |
| alternate_fast48 | ROM24 + VBD24, 조건부 즉시 복귀 구조 | 280.10초 | 153.08mm | 181.87mm/s |
| alternate_masked24 | ROM12 + VBD12, 고정 마스크 그래프 | 179.88초 | 153.85mm | 614.97mm/s |
| vbd24_control | VBD24 | 108.53초 | 0.0024mm | 0mm/s |

VBD24 대조군의 빠른 종료·정지는 성공적인 집기 후 안착이 아니다. 양측 접촉과 상승을 실패했고 압착에 따른 추가 주름도 생성하지 못했다. 반면 ROM12+VBD12는 상승과 압착을 수행했다. 따라서 48회 고정만이 유일한 방법은 아니며, 이 장면에서 reduced correction이 낮은 반복 예산의 집기 결과를 바꿀 수 있다는 근거가 생겼다. 일반적인 수렴 속도 우위를 증명한 것은 아니다.

첫 교대48 실험은 ROM372,864회를, 고정 그래프24 실험은177,792회를 수행했고 이 궤적에서는 모든 보정을 승인했다. 유한 상태와 충돌 절단을 통과했다는 의미이며 힘 잔차/정확도 검사를 통과했다는 의미는 아니다. 첫 교대48과 고정 그래프24는 반복 수까지 다르므로 두 실행 시간의 차이를 조건부 그래프 제거만의 효과로 주장하지 않는다.

고정 그래프24의 같은 토폴로지 기준과 강체 정렬한 형상 RMS는 7초0.94mm, 9초0.50mm이지만 압착 후12초48.44mm,16초74.59mm로 커진다. 기준 자체의 낙하 후 큰 진동도 있어 이 수치가 후보의 절대 오차는 아니다. 집기 구간의 패드 상대 이동은 최대8.21mm, 압착까지 포함하면77.72mm이다. 낙하 후 안정화와 압착 형상은 추가 작업이 필요하다. 모든 완성 후보의 기본 GUI 승격은 보류했다.

검증: 전체72개 회귀 검사 통과. 새 검사는 닫힌 비균일 격자, 교대/최종 VBD 스케줄, 소변형/항복 재질 분기, CUDA Graph의 즉시 복귀와 고정 마스크 승인·거절·비정상값 경로를 포함한다. `--exploratory`에서도 유한값/폭주 검사는 유지하고, 기존 물리 품질 지표는 종료 후 그대로 보고했다.
