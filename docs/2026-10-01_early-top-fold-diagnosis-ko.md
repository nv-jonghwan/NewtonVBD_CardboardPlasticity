# 집기·상승 단계의 윗면 조기 접힘 진단

관찰한 현상을 물리 메시에서도 재현했다. 압착 단계는 9초에 시작하지만, 윗면은 집기 전부터 약 14.5 mm 처져 있고 집기 종료에는 24.2 mm, 상승 중에는 37.1 mm 처진다. **초기 자중 처짐과 안쪽 손가락 링크의 상단 모서리 압박이 겹친다.** 손끝 접촉력만 보면 먼저 발생한 링크 접촉을 놓친다. 이번 VBD 실행 순서 최적화 이전 기록에서도 같은 초기 변형이 나타난다.

## 측정 방법

- 현재 `demo_scene_robotiq_board10_primitive.usda`, Newton 1.6.0, guarded VBD, 물리 정점 3,458개를 사용했다. GUI를 유지하고 유휴 GPU 1에서 독립 실행했다.
- 윗면 625개 정점 중 중앙 25개의 평균 위치와 테두리 96개에 맞춘 평면 사이의 법선 방향 거리를 처짐으로 정의했다. 상자의 상승·기울기와 중앙 변형을 분리한다. 표시용 메시 보간에서 생긴 착시만으로 설명할 수 없다.
- 60 Hz로 모든 강체의 접촉력 및 윗면 내부 소성 힌지 수를 기록했다. 접촉력은 마지막 substep 상태에서 기존 Newton 접촉식으로 수집한 강체 반력의 합벡터 크기이며, 프레임 평균 또는 개별 접촉력 크기의 합은 아니다.
- 윗면 내부 힌지 1,680개 중 누적 소성각이 `1e-4 rad`를 넘은 개수를 집계했다. 모서리의 인접 옆면을 포함하는 힌지는 이 집계에서 제외한다. 최초 발생 시점은 60 Hz 샘플 기준이다.

## 1. 손끝보다 안쪽 링크가 먼저 접촉한다

| 시점 | 윗면 처짐 | 손끝 몸체 좌/우 접촉력 | 안쪽 링크 좌/우 접촉력 | 윗면 소성 힌지 |
|---|---:|---:|---:|---:|
| 집기 직전 5.0 s | 14.52 mm | 0 / 0 N | 0 / 0 N | 0 |
| 집기 중 6.0 s | 17.12 mm | 0 / 0 N | 224.53 / 224.50 N | 0 |
| 집기 종료 7.0 s | 24.18 mm | 90.14 / 81.13 N | 192.58 / 186.30 N | 52 |
| 상승 중 8.0 s | 37.13 mm | 413.02 / 391.50 N | 379.60 / 420.20 N | 66 |

`left_inner_knuckle` 및 `right_inner_knuckle`은 5.367초에 1 N을 넘는다. 첫 윗면 소성 변형은 6.067초, 손끝 몸체 접촉은 6.133초다. 첫 소성 힌지의 초기 위치는 상자 중심 기준 약 `(-95.5, -70.3, +97.0) mm`로, 윗면 중앙 한 점에서 시작하는 것이 아니다. 모서리 부근의 국부 항복과 윗면 전체 처짐을 구분해야 한다.

기록된 강체 자세와 실제 박스 충돌체를 재구성했다. 5.5/6/7초에서 각 안쪽 링크에 7 mm 이내로 가까운 정점은 11개씩이며 모두 윗면 좌우 상단 모서리다. 초기 좌표는 `x=±134.887 mm, y=-41.346…+41.346 mm, z=96.985 mm`다. 이는 근접 정점 진단이며 접촉 삼각형 내부의 정확한 적분점 목록은 아니다. 별도로 실제 링크 반력이 확인되어 접촉 발생 자체는 명확하다. 7초 두 링크의 위쪽 반력은 합계 약 338.5 N이므로 상자에는 그 반대 방향의 힘이 작용한다.

현재 충돌체는 원본 링크 메시를 감싸는 상자다. 접촉이 원본 형상에서도 동일하게 발생할지, 보수적인 박스 모서리 때문에 일찍 발생할지는 원본 메시와의 접촉 비교가 추가로 필요하다. 따라서 링크 충돌을 영구히 삭제하는 것이 바로 올바른 수정이라고 단정하지 않는다.

## 2. 접촉을 제외한 비교 시험에서 윗면 접힘이 크게 줄었다

양쪽 안쪽 링크의 충돌만 비활성화하고 다른 물성·명령·접촉·해상도를 유지했다. 이 변형은 진단용 장면에만 적용했다.

| 진단 조건 | 7 s 처짐 / 윗면 소성 힌지 | 8 s 처짐 / 윗면 소성 힌지 | 9 s 처짐 / 윗면 소성 힌지 |
|---|---:|---:|---:|
| 현재 장면 | 24.18 mm / 52 | 37.13 mm / 66 | 33.69 mm / 66 |
| 안쪽 링크 충돌 제외 | 14.20 mm / 0 | 8.62 mm / 4 | 8.08 mm / 4 |
| 집기 힘 기준 250→80 N | 17.30 mm / 2 | 14.68 mm / 23 | 5.92 mm / 23 |

링크 충돌 제외 시 9초 바닥 정점은 집기 전보다 약 185 mm 상승해 들어올리기는 유지됐다. 그러나 전체 소성 힌지는 203개로 현재 장면의 197개보다 많다. 다른 면의 변형까지 해결됐다는 뜻은 아니다. 접촉 순서와 하중 전달 자체를 바꾸는 원인 분리 시험이며, 9초 이후 압착·낙하·정착 검증도 수행하지 않았다.

80 N 시험에서도 상승은 유지됐지만, 8초 손끝 접촉력은 약 379/325 N이다. `graspForce`는 입력 관절 스프링의 힘 환산 기준이다. 감쇠, 별도의 핀치 자세 스프링 및 접촉 반력에 대한 실제 힘 상한이 아니다. 현재 `250 N`이나 GUI의 손끝 수치만으로 약하게 집는다고 판단할 수 없다. 힘을 줄이면 조기 변형은 감소하지만 초기 자중 처짐과 힘 제한 의미의 문제까지 해결되지 않는다.

## 3. 접촉 전 14.5 mm 처짐은 별도의 보정 대상이다

처음 평평했던 윗면은 중력이 들어오며 처지고, 약 1.717초에 sleep 상태가 되어 그 형상을 유지한다. 소성 힌지는 0개다. 따라서 이 단계는 현재 구성식상 영구 접힘이 아니라 탄성/수치 응답이다.

| 별도 2초 시험 | 2초 윗면 처짐 | 소성 힌지 |
|---|---:|---:|
| 현재 설정 | 14.48 mm | 0 |
| 중력 0 | -0.0004 mm, 사실상 0 | 0 |
| substep당 셸 반복 17→48 | 10.55 mm | 0 |
| 굽힘 MD/CD 계수 4배 | 4.66 mm | 0 |

중력에 의해 발생하며 굽힘 계수와 반복 예산 모두에 민감하다. 반복 증가 시험은 2초 시점의 비교로, 정적 평형까지 수렴했다는 증거가 아니다. 4배 시험에서는 강성 비례 굽힘 감쇠와 항복 모멘트도 함께 증가한다. 소성이 발생하지 않았으므로 초기 처짐 차이가 소성 손상의 결과는 아니지만, 순수 정적 강성 보정값으로 바로 채택해서는 안 된다.

현재 윗면 내부 항복각은 요소 폭에 따라 약 2.29–3.86도다. 이는 전체 패널의 기울기 기준이 아니라 인접 삼각형 사이의 국부 각도 기준이다. 항복 기준만 높이면 집기 전 탄성 처짐은 해결되지 않는다. 정적 자중 시험의 수렴을 먼저 확보하고 실제 판의 굽힘/항복 측정값으로 보정해야 한다.

## 4. 최근 최적화와의 관계

기존 `outputs/vbd_optimized/baseline_b`는 5/7/8초 처짐이 약 14.52/24.19/36.98 mm다. guarded 세 반복도 각각 약 14.52/24.18–24.19/36.99–37.12 mm로 일치한다. 조기 처짐은 최적화 전에도 존재했고, 이번 guarded 스케줄 변경이 새로 만든 현상이라는 근거는 없다. 이는 초기 구간 진단이며 전체 비선형 궤적의 동일성을 주장하지 않는다.

## 수정 우선순위와 현재 상태

1. 안쪽 링크 충돌체가 원본 형상보다 과도하게 상단 모서리에 진입하는지 검증하고, 집기 높이·접근 자세·충돌체 형상을 조정한다. 진단용 충돌 제거를 그대로 정식 설정으로 승격하지 않는다.
2. 손끝 외 링크 접촉력도 표시하고, 집기 힘 명령과 실제 반력의 차이를 드러낸다. 낮은 집기 힘 및 목표 간격을 전체 시나리오에서 검증하고, 필요하면 실제 접촉력 피드백 제어를 적용한다.
3. 접촉 없는 자중 처짐의 반복/시간 수렴을 확인한 뒤 굽힘 물성을 보정한다. 항복값만 올리거나 표시 표면만 평평하게 만드는 방법으로 현상을 감추지 않는다.

이번 작업은 원인 진단까지 완료했다. 정식 장면·솔버·재료와 실행 중 GUI는 변경하지 않았다. 진단 스크립트 및 분리된 시험 장면·기록·그림만 추가했다. 실제 골판지의 정량 실험값이 없으므로 현재 처짐의 실물 대비 오차량은 확정할 수 없다.
