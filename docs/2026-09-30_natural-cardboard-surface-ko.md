# 구겨진 골판지 표면의 격자 느낌 완화

확대 Robotiq 모드의 상단 주름에서 보이던 삼각형·계단 형태를 완화했다. 실제 계산된 큰 접힘과 원본 종이 텍스처를 유지하면서 표시용 표면을 보정한다.

## 원인과 변경

물리 셸은386정점/768삼각형이고 화면용 표면은57,280삼각형이다. 기존에는 표시용 곡면을 보간해도 두께·베벨 오프셋이 각 물리 삼각형의 일정한 법선을 따라갔다. 약7.5mm의 바깥쪽 오프셋이 굽힌 면의 경계에서 서로 다른 방향으로 이동하면서 단차와 격자 모양을 강조했다.

`PanelSurface`의 `smooth_thickness` 옵션은 같은 원래 박스 면에 속하는 주변 삼각형의 두께 오프셋 벡터를 면적 가중 평균하고 보간한다. 깊은 접힘에서도 공유 경계의 표시 위치를 일치시켜 톱니 형태를 줄인다. 평균 벡터를 다시 단위 길이로 늘리지 않아 접힌 외피가 부풀지 않게 한다. 접선 방향 오프셋은 기존 방식을 유지한다. Robotiq 장면에만 `cardboard:visualSmoothThickness=true`를 설정했다. 다른 기존 장면은 기본값false로 이전 동작을 유지한다.

Robotiq의 표시용 주름 기준각은45→100°, 전이 폭은10→40°로 조정했다. 이는 물리 재료의 항복각이 아니다. 완만한 면과 직각 부근의 굽힘을 연결하며,120° 이상의 매우 깊은 접힘에서는 중심면과 음영의 주름을 유지하면서 바깥쪽 두께 표현은 연속적으로 연결한다. 원래 박스 면의 경계는 유지한다. 원본 UV·텍스처·물성·물리 정점·접촉·그리퍼 설정은 동일하다.

`render_snapshot.py`도 GUI와 같은 곡면·법선 설정을 소비하도록 변경했다. 기존 스크립트는 단순 선형 스키닝만 사용해 GUI와 표면이 달랐다.

## 검증

동일한16초 기록에서 시작·압착·최종 상태를 포함한50개 프레임을 비교했다.

| 항목 | 결과 |
|---|---:|
| 압착 상태의 완만한 경계 두께 단차 RMS |1.378→0.000mm|
| 최종 상태의 완만한 경계 두께 단차 RMS |1.242→0.000mm|
| 비교 프레임 전체의 최대 표시 정점 이동 |7.14mm|
| 프레임별 표시 이동 RMS의 최대값 |1.10mm|
| 표시 표면 평가 시간 중앙값 |약12ms|

단차 수치는 원래 박스 모서리와40° 이상 접힘을 제외한1,018개 경계에서, 양쪽에 동일한7.5mm 오프셋을 준 진단용 샘플을 비교한 값이다. 이 이상화한 공유 경계 샘플에서 단차가 제거됐다는 의미이며, 원본 베벨·면 경계까지 포함한 화면 전체 오차가0이라는 뜻은 아니다.

- 24개 단위·기하 회귀 검사 통과. 새 검사는 두꺼운 표면의 평면·강체 변환 보존, 완만한 공유 경계 단차 제거,130° 깊은 접힘의 중심면/음영 보존과 두께 위치 연속성을 확인한다.
- 7개 표시 검증 기준 통과: 표시 설정3개 외의 USD 속성/연결/관계 동일, 초기 형상 동일, 유한 좌표·단위 법선, 최대 표시 이동8mm 미만, 단차50% 이상 감소, 물리 기록 해시 불변.
- 기존16초 물리 기록을 그대로 사용한다. 표시 보간이 물리 접촉이나 영구 소성 상태를 바꾸지 않는다.

검증 스크립트:

```bash
./scripts/python.sh scripts/build_scaled_robotiq.py
./scripts/python.sh -m unittest discover -s tests -v
./scripts/python.sh scripts/validate_surface_refinement.py
./scripts/python.sh scripts/live_isaac.py --quality robotiq
```

비교 기준 자산은 `assets/demo_scene_robotiq_surface_baseline.usda`에 보존했다. 초기75° 후보와 최종100° 후보의 비교 기록은 `outputs/surface_refinement/`에 있다. 최종 자산은 생성기로 재현되며 검증 후보와 바이트 단위로 일치한다.

첫 후보 GUI 검증에서 네이티브 `malloc_consolidate` 오류가 한 번 발생했다. 실패 로그를 보존하고 해당 프로세스만 정리한 뒤 재실행한 제어/전체 기록 재생 검사는 통과했다. 네이티브 오류의 근본 원인은 확정하지 않았다.

## 확인과 한계

오른쪽 **Recorded replay**로 같은 압착 결과를 개선된 표면으로 볼 수 있다. **Play / Resume**으로 새 계산을 실행해도 같은 표면 보간을 적용한다.

이번 개선은 시각적 재구성이다. 물리 메시 해상도를 늘리거나 실제 골판지의 미세 주름·골 구조·찢어짐을 새로 계산한 것은 아니다. 매우 깊은 접힘과 원래 면 경계에는 거친 물리 메시의 흔적이 일부 남을 수 있다. 표시 표면과 충돌용 셸이 완전히 일치하는 정밀 접촉 시각화로 해석하지 않는다.
