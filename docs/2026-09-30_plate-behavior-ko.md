# 골판지 판 강성 및 표시 표면 수정

이 문서는 앞선 dense 조정 결과를 대체하는 후속 검증 기록이다. 기존 결과는 낙하 뒤에도 계속 접혀 상자 형태가 무너졌으므로 골판지 거동으로 합격 처리할 수 없었다.

## 원인과 이론

기존 dense 결과의 14→16초 내부 부피는 0.008276→0.004322 m³로 47.78% 감소했다. 같은 기간 표면적 변화는 -0.0175%였다. 따라서 주된 문제는 면내 신축이 아니라 **굽힘을 통해 상자 전체가 계속 붕괴하는 현상**이다. membrane 강성과 폴리곤 수만 올려서는 해결되지 않는다.

현재 모델의 판 굽힘 에너지는 각 힌지에서 다음과 같다.

`E_b = 0.5 × D × (edge_length / dual_width) × (theta - theta_reference - theta_plastic)^2`

손상되지 않은 면 내부에서는 기준각과 소성각이 0이므로 평평한 상태로 돌아가려는 모멘트가 생긴다. 실제로 항복한 힌지에서만 소성 기준각이 바뀌어 영구 주름이 남는다. 제조된 상자의 모서리는 처음부터 90도 기준각을 가진다. 이런 기준각 기반 셸 모델의 근거는 [Discrete Shells](https://www.multires.caltech.edu/pubs/Shells.pdf)다.

골판지의 판 부분과 주름 부분은 굽힘 저항이 다르며 이를 구분해야 한다는 점은 [Numerical Modelling of Corrugated Paperboard Boxes](https://www.mdpi.com/2297-8747/29/4/70)에서도 다룬다. 본 데모는 그 논문의 보정된 재료를 그대로 구현한 것이 아니라, 기존 Newton 삼각형 셸의 굽힘/항복/손상 계수를 조절한 정성적 근사다. 전체 직교이방성, 코어 압궤와 박리는 구현하지 않았다.

`bendingMD/CD = 0.6/0.3, yieldCurvature=25`의 첫 시험은 판은 유지했으나 상자를 제대로 들지 못하고 주름도 만들지 못했다. 이 결과는 채택하지 않았다.

## 표시 표면

`CardboardBindingAPI`에 `surfaceInterpolation`과 `visualCreaseAngleDegrees`를 추가했다. `creaseAwareCubic` 모드는 다음을 수행한다.

- 물리 정점을 통과하는 삼차 곡면 패치로 표시 메쉬만 보간한다. 물리 입자나 접촉 계산을 바꾸지 않는다.
- 평평한 판은 정확히 평면으로 유지한다. 상자의 원래 모서리와 45도 이상의 접힘은 날을 유지한다.
- 인접 패치의 변 제어점을 공유해 틈을 방지한다. 원본 텍스처 UV는 그대로 사용한다.
- 부드러운 영역에는 연속적으로 보간한 정점 법선을 사용한다. source bevel offset은 삼각형의 변형 좌표계와 함께 회전한다.

기하 보간은 [Curved PN Triangles 원 논문](https://alex.vlachos.com/graphics/CurvedPNTriangles.pdf)의 삼차 패치 구성을 응용했다. 본 구현의 법선은 주름을 구분하는 선형 보간이며 논문의 이차 법선 패치와 동일하지 않다. 모든 곳에서 접선 연속성을 보장하는 방식은 아니고, 물리 해상도 이하의 실제 주름을 새로 계산하지도 않는다.

평면 보존, 회전 및 두께 오프셋의 객관성, 곡면 공유 변의 무틈, 날카로운 주름 보존을 단위 검사했다. GUI의 live 제어 및 녹화 재생 검사도 수행했다. `outputs/plate_surface_check/gui_crush.png`는 **기존 dense 물리 기록에 새 표시 방식만 적용한 비교 화면**이며 새로운 물성의 검증 결과가 아니다.

## 정량 검증

후속 물성 실행의 전체 집기·압착·낙하 결과와 부피 유지 지표를 이 절에 기록한다. `measure_shape_retention.py`는 축 정렬 bounding box 대신 회전·이동에 불변인 폐곡면 부피와 표면적을 사용한다. `locally_flat_area_fraction_3deg`는 원래 같은 판에 속하는 이웃 삼각형 사이 각도가 모두 3도 이하인 삼각형의 면적 비율이며, 실제 판 전체의 평면 오차나 실물 보정 지표는 아니다.

### 강성 우선 비교안 (plate_balanced)

굽힘 0.2/0.1 N m, 항복곡률 12 m⁻¹, 손상률 0.15, 잔류강성비 0.65에서 16초 전 과정을 실행했다. 기존 대비 굽힘은 약 5배다. 집기 힘 18→30 N, 집기 목표 255→240 mm, 압착 목표 190→160 mm이며 압착 힘 상한은 70 N을 유지했다.

- 상자 들림 90.4 mm, 압착 후 실제 개구 252.5 mm.
- 소성 힌지 64개(낙하 후 85개), 최대 소성각 0.0755 rad.
- 14→16초 부피 감소 0.134%, 최종 최대 속도 6.48 mm/s.
- 8개 단위 검사와 12개 동작 검사는 통과. 그러나 최대 영구각이 작아 시각적으로 대부분 원상 복귀하는 편이었다. 판 형태 유지에는 성공했지만 주름 표현을 위한 최종안으로는 채택하지 않았다.
- 이 결과를 보고 최종 평가에 최대 영구각 0.15 rad 초과 및 강체운동을 제거한 잔류 형상 RMS 1 mm 초과 조건을 추가했다. 이 기준은 본 데모의 정성적 표시 목적이며 실물 실험에서 유도한 허용치가 아니다.

### 최종 채택안: plate_crease

강성 우선 비교안과 같은 굽힘 0.2/0.1 N m, 손상률 0.15, 잔류강성비 0.65 및 그리퍼 설정을 유지하고 **항복곡률만 12→5 m⁻¹**로 낮췄다. 기존 dense 값과 비교하면 membrane 17640/29400은 그대로이고, 굽힘은 약 5배, 굽힘 감쇠는 0.0006→0.003, 경화비는 0.01→0.02다. 기존 dense 잔류강성비 0.25보다 높은 0.65를 사용해 손상된 곳도 과도하게 천처럼 약해지지 않도록 했다. 굽힘 기준각/국부 손상 모델 자체는 유지했으며, 강체 판 부착이나 물리 후처리로 형상을 강제한 것이 아니다.

| 측정 항목 | 최종 결과 |
|---|---:|
| 집기 전 소성 힌지 | 0 |
| 테이블 위 들림 | 91.4 mm |
| 압착 후 실제 그리퍼 개구 | 243.9 mm |
| 압착 후 / 최종 소성 힌지 | 733 / 2515 (전체 10368) |
| 최대 영구 접힘각 | 35.2° |
| 최종 체적 / 초기 체적 | 96.81% |
| 14→16초 체적 변화 | +0.114% |
| 최종 잔류 형상 RMS (강체운동 제거) | 3.44 mm |
| 최종 국부 평탄 면적 비율 (이웃각 3° 기준) | 89.4% |
| 최종 최대 입자 속도 | 10.86 mm/s |

8개 단위 검사, 10개 자산 검사, 12개 시나리오 검사, 9개 판 거동 검사를 통과했다. 낙하 충격 자체로는 주름이 늘어나지만 14초 이후 소성 힌지 수는 증가하지 않는다. 압착력과 그리퍼 실제 개구를 비롯한 전체 기록은 `outputs/plate_crease`에 저장했다. **기존 dense와 그리퍼 초기 집기 설정도 달라졌으므로 재료 하나만 바꾼 통제 실험으로 해석하면 안 된다.**

이 결과는 해당 16초 시나리오에서 판 유지와 국부 영구 변형을 확인한 것이다. 최종 속도가 완전히 0은 아니며 장시간 평형·메쉬 수렴·실물 강도 보정은 별도다. 체적은 닫힌 삼각형 표면의 부호 있는 기하 체적이고, 국부 평탄 면적은 위에서 정의한 기하 지표다. 인위적인 체적 보존 압력, 속도 강제 정지, 부착 constraint 또는 미리 만든 찌그러짐 애니메이션은 사용하지 않았다.

최종 Isaac GUI에서도 live Play/Pause/Reset과 Recorded replay의 일시정지·재개·마지막 프레임 검사를 통과했다. 실제 RTX 압착 화면과 낙하 후 화면은 `outputs/plate_crease/gui_crush.png`, `gui_settled.png`다. GUI 기본 scene/replay를 이 최종안으로 변경했다.
