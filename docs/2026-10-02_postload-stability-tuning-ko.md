# 하중 제거 후 추가 접힘을 줄이는 수정

이 문서는 재료 계수 변경 후보가 실패한 앞선 실험 기록이다. 이후 각도 저항을 추가한 수정은 [접힌 힌지의 각도 저항](2026-10-02_crease-friction-fix-ko.md)을 참고한다.

현재 상태: 힘/에너지 구현 검증은 통과했으나, 전환·경화 후보의 형상 개선은 반복 실행에서 재현되지 않았다. GUI 물리 설정은 아직 이전 값을 유지한다.

앞선 진단에서 확인한 추가 접힘을 줄이기 위해, 영구 접힘각은 보존하면서 소성 이력에 따른 강성 감소를 조정한다. 그리퍼가 떨어졌다는 이유로 변형을 고정하거나 특정 시각 이후 소성을 끄지 않는다. 중력·착지·자체 접촉에 대한 반응은 계속 계산한다.

## 점진적 초기 강화 해제

기존 초기 강화는 누적 소성각이0보다 크면 바로 해제됐다. 새 옵션 `--small-bend-memory-curvature`는 소성 곡률 `누적 소성각 / 힌지의 dual width`에 따라 강화를 연속적으로 줄인다.0이면 기존 법칙을 유지한다.

전환 곡률을 `c`, 누적 소성각을 `a`, dual width를 `h`라 하면:

```
x = clamp(a / (h*c), 0, 1)
w = 1 - x*x*(3 - 2*x)
effective_scale = 1 + (initial_scale - 1)*w
```

작은 소성 이력 때문에 갑자기 주변 패널이 약해지는 전환을 완화한다. 충분히 접힌 힌지는 기존 큰 곡률 법칙으로 돌아간다. 이미 만들어진 소성 rest angle은 지우지 않으며, 하중이 다시 커지면 추가로 접힐 수 있다. 이 전환 값은 실물 시험으로 보정된 재료 상수가 아닌 실험 옵션이다.

힘·양의 근사 접선은 일반 VBD, 국부 VBD/Jacobi, ROM의 전체/대표 요소 힘 평가에 동일하게 적용한다. 고정 CUDA graph 안에서 GPU가 기존 소성 이력을 읽어 계산하며, 반복마다 CPU로 상태를 가져오지 않는다.

## 에너지 처리

초기 강화의 추가 탄성 에너지는 큰 곡률에서 일정한 offset이다. 전환 종료 곡률은 원래 항복 곡률보다 작고, 소성 반환 사상 후에도 탄성 곡률은 그 종료값 이상이다. 따라서 소성 이력이 갱신되는 순간 추가 에너지의 감소를 다음과 같이 계산할 수 있다.

```
C = 0.5 * base_ke * edge_length * dual_width^2
    * (initial_scale - 1) * knee * end
released = C * [(1-old_damage)*old_w - (1-new_damage)*new_w]
```

강화 감소와 남아 있는 강화의 손상에 따른 에너지 감소를 모두 소산 이력에 더한다. 서브스텝별 감소량이 망원합이므로 프레임 시작/끝 상태로 합산할 수 있다. 에너지 계측 커널은 프레임당 한 번이며, 힘이나 소성각을 나중에 바꾸는 보정은 아니다. 기존 binary 모드는 이전의1회 에너지 계측을 유지한다.

## 비교 범위

같은4mm 비균일 격자, 그리퍼 동작, S16 초기 곡률 법칙과 접힘 보존 렌더링을 사용한다. 전체16초 동작을 GPU1에서 순차 실행하여 다음을 구분한다.

- 같은24회 반복의 기존 기준.
- 전환 곡률15만 추가한 후보.
- 재료는 유지하고48회 반복으로 늘린 비교.
- 손상 후 굽힘 강성 하한만18%→45%로 올린 후보.
- 점진 전환과45% 하한을 함께 적용한 후보.

부피는 자기교차 시 실제 내부 공간으로 해석할 수 없는 폐곡면 부호 부피 지표이므로, 볼록 외곽 부피와 패널 중심 거리도 함께 본다. 하중 제거 직전12초와 마지막16초뿐 아니라 중간 변화, 소성 이력, 파지 유지, 잔진동을 함께 확인한다. 반복 횟수 비교 한 번만으로 수치 수렴이나 물리적 정확성을 확정하지 않는다.

## 구현 검증

전체88개 회귀 검사 통과(`outputs/postload_fix/regression_complete.log`). 소성 경화 비율0.1/0.2의 반환 사상과 제하 후 영구각 보존 검사도 포함한다. 점진 강화 힘의 에너지 수치 미분 일치, 첫 항복에서의 연속성, 완전히 연화된 경우 기존 법칙 회복, 에너지 감소량의 서브스텝 합산 일치, ROM과 VBD의 같은 힘 계산을 검증했다. 국부 Jacobi와 ROM의 상태별 힘 평가도 비교했다. 손상 강성을 남겨도 소성 rest angle에서 추가 이력이 생기지 않으며, 재하 시에는 추가 소성이 가능한 것을 검사했다.

새 Hessian 비교의 최초 절대허용값1e-4는 GPU 원자 합산 순서로 생기는 약1e-3의 영점 근처 비대각 성분 차이에 걸렸다. 기존 요소/정점 합산 비교와 같은 절대허용값0.003을 사용하고, 각3×3블록 전체의 상대 Frobenius 오차2e-6 검사도 추가했다. 힘 검사는 그대로 유지했다. 이는 solver 실패를 숨긴 것이 아니라 약1e5 크기 행렬의 float32 합산 오차를 구분한 것이다.

## 첫 비교와 반복 검증

아래 값은12초→16초 폐곡면 부피 지표와 볼록 외곽 부피의 변화율이다.12초는 손가락 열기 명령 시작이며, 실제 손가락 하중은 그 뒤에도 잠시 남는다. 낙하·착지 변형도 이 구간에 포함되므로 무하중 크리프 비율로 해석하지 않는다.

| 계산 | 폐곡면 부피 변화 | 외곽 부피 변화 | 판단 |
|---|---:|---:|---|

| `reference24` | -17.95% | -15.31% | 채택하지 않음 |
| `memory15` | -19.78% | -22.05% | 채택하지 않음 |
| `reference48` | -17.49% | -5.20% | 채택하지 않음 |
| `floor45` | -29.01% | -27.11% | 채택하지 않음 |
| `memory15_floor45` | -51.06% | -42.94% | 채택하지 않음 |
| `hardening10` | -6.25% | -17.47% | 채택하지 않음 |
| `hardening20` | -4.61% | -11.35% | 반복에서 개선 재현 실패 |
| `residual_checked24` | -20.73% | -24.31% | 채택하지 않음 |
| `hardening20_long` | -41.00% | -32.69% | 반복에서 개선 재현 실패 |

`reference48`은48회 혼합 ROM/VBD 계산이며 완전 VBD 기준은 아니다. `residual_checked24`는 ROM 잔차 재검사를 켜는 동시에 해당 경로가 요구하는 전체 요소 힘 계산을 사용한다. 최초 대표 요소 조합은 초기화에서 거절되어 실패 폴더를 별도 보존했다. 잔차 검사 한 항목만의 독립 효과로 해석하지 않는다.

초기 `hardening20`은 점진 전환15와 소성 경화 비율0.2의 조합으로,16초 부피 감소4.61%, 그립 기준4/5를 보였다. 그러나 같은 설정의20초 재실행에서는 같은12→16초 구간부터41.00% 감소했고,12→20초44.18% 감소했다. 개선이 단순히 늦어진 문제가 아니라 반복 간 접힘 경로도 달라졌다. 좋은1회 결과를 근거로 안정화 완료를 선언하거나 GUI 기본값으로 승격하지 않았다. 원인에 대한 결정론적 재현성은 아직 입증하지 못했다.

부피만 줄이는 튜닝을 채택하지 않는다. 예를 들어 `hardening10`은 감소량6.25%였으나 양쪽 접촉·기하학적 파지 검사를 통과하지 못했다. 강성 하한45% 후보들은 추가 접힘이 오히려 커졌다. 따라서 전역 강성·경화 증가만으로 해결됐다고 판단할 수 없다.

추가로 전환 곡률150과 완전 VBD48회 기준도 비교했다. 실험 옵션 구현과 힘/에너지 회귀 통과는 전체 동작의 형상 안정성이나 실물 물성 보정을 보증하지 않는다.

## 접힘 주변의 작은 변형 저항 유지 후보

전환 곡률을15→150으로 늘린 `memory150`은 초기 평평한 패널의 강성을 더 높이지 않는다. 같은S16에서 시작해, 소성 이력이 생긴 뒤 그 영구각 주변의 강화가 더 천천히 줄어들게 한다. 큰 탄성 곡률의 모멘트 법칙과 항복 기준은 기존 값을 유지하며, 경화 비율0.01·손상 속도4·손상 후 강성 하한18%도 유지한다.150은 이번 장면의 실험 설정이며 실물 보정값이 아니다.

첫20초 실행에서12→16초 폐곡면 부피는4.398→5.408L(+22.97%), 외곽 부피+9.09%로 일부 복원되었다. 초기 부피11.275L에 비하면 영구 압착은 남아 있다.18→20초 외곽 부피−0.49%, 반대 패널 중심 거리 변화−1.38/+0.11/−0.89mm, 최종 최대 속도30.24mm/s였다. 강제로 위치를 고정하거나 소성 이력을 지우지 않았다.16초까지 실행시간81.87초(새 기준80.65초),20초까지123.30초이며 공유 GPU 환경의 단회 값이다.

그립4/5: 전체 보유 구간, 해제 전 테이블 복귀 없음, 양쪽 접촉, 손끝 기하학적 관여는 통과했다.20mm 재료점 이동 한계는 실패했으므로 무슬립으로 표현하지 않는다. 강한 압착 중과 낙하 후의 접힘 형상이 기준과 완전히 같다고 주장하지 않는다. 비교 형상은 `outputs/postload_fix/memory150_shape_review/solver_shapes.png`에 있다.

같은 전환150에 경화0.2를 병용한 후보는12→16초−37.97%,12→20초−38.66%로 악화되어 채택하지 않았다. 단순히 경화를 더 높이는 방향이 적합하다는 근거는 없다.

시험용 미리보기 실행기로 headless GUI에서 Play/Pause/Reset, 해당20초 녹화의 Replay/Pause/Resume/최종 프레임 검사가 통과했다(`outputs/postload_fix/memory150_gui_controls.log`,PID425877,종료0). 이는 시각 창 확인과 별개다. 반복 검증 실패 후 시험용 실행기를 제거했으며 기존 데스크톱 설정은 유지했다.

### 전환150 반복 검증: 채택 보류

`memory150_repeat`는 같은 설정에서12→16초 폐곡면 부피−40.31%, 외곽 부피−41.52%,12→20초−38.90%를 보였다.18→20초에는 외곽 부피+0.22%로 작게 변했지만, 그전에 추가로 많이 접힌 상태였다. 최종 속도118.36mm/s, 그립4/5였다. 따라서 첫 실행의 탄성 복원을 재현 가능한 개선으로 일반화하지 않으며, 전환150 단독 후보도 채택하지 않는다.

완전 VBD48회(`full_vbd48`, ROM/국부Jacobi 없음)는12→16초 부피−48.90%, 최종 속도974.34mm/s로 크게 움직였다.20초에 최저 높이가−3.00mm로 바닥까지 내려왔으므로 테이블 위 안정화 기준과도 맞지 않는다. 이 결과는 더 많은 반복이 더 좋은 모습을 보장하지 않음을 보여주며, 수렴된 정답 해석으로 사용하지 않는다.

손상 누적 속도를4→1/0.5로 낮추고 전환150을 병용한 추가 비교도 수행했다. 초기 재료 강성, 큰 곡률 항복, 경화 비율은 유지한다. 실패 후보들을 사용자 GUI에 자동 반영하지 않는다.

초기 손상속도 overlay는 중첩 prim 선언을 한 줄에 넣은 USDA 구문 오류로 초기화에 실패했다. 기존의 정상 overlay 형식으로 수정했고, 실패 출력은 `damage1_memory150_initialization_failed`에 보존했다. 이 실패는 물리 결과 비교에서 제외한다.

### 손상 누적 속도 비교

손상 속도1 + 전환150은12→16초 부피−12.78%로 일부 줄었지만 외곽 부피−18.80%, 최종 속도279.33mm/s로 전체 안정성 개선을 확인하지 못했다. 손상 속도0.5 + 전환150의GPU0 실행은12→16초 부피−19.14%, 외곽 부피−25.64%여서 기준보다 개선되지 않았다. 두 후보 모두 초기 강성을 높이지 않은 비교다. 손상 속도만 낮추어 원하던 거동을 얻었다고 판단하지 않는다.

시험용 GUI 실행기를 제거했다. 구현한 옵션과 모든 실패/성공 표본은 진단·후속 개발을 위해 남기며, 기존 `scripts/live_flat_panels.sh`의 물리 프로필 및 현재 데스크톱 GUI는 유지한다. 초기 좋은 표본의 Replay를 개선 완료 결과로 띄우지 않는다.

손상 속도0.5 + 전환150의GPU1 재실행은12→16초 부피-4.91%, 외곽 부피-15.15%, 최종 속도68.11mm/s였다. GPU0 실행을 포함해 안정적 개선을 확인하지 못했으므로 채택하지 않는다.

## 최종 상태

총16개 전체 동작 계산과88개 회귀 검사를 수행했다. 구현된 점진 강화 해제와 에너지 계측은 opt-in으로 남겼지만, 추가 수축을 반복적으로 줄이는 물리 프로필은 확보하지 못했다. 수정 완료·안정화 완료로 표시하지 않는다. 모든 완료 실행의 물성 유한성, 손상 범위, 소성 이력 및 소산 이력 검사는 통과했다. 이 검사는 원하던 형상이나 안정화의 합격을 의미하지 않는다.

비교 자료: `outputs/postload_fix/comparison.json`, `comparison.png`, `material_all.json`, `regression_complete.log`. 초기화 실패2건은 전체 동작16건에서 제외했다. 기존 GUI PID410405/window0x300000d가 계속 표시되며 실제4mm/S16/24회 프로필과1402개 유한 정점을 확인했다(`retained_gui_verification.json`). 새 후보를 기본 실행기나 데스크톱 물리에 적용하지 않았다.

낙하 충격과 압착 중 잔류 응력, 접촉/소성 갱신의 수치적 민감성을 구분하는 검증은 여전히 필요하다. 이번 비교만으로 어느 하나를 유일한 원인으로 확정하지 않는다.
