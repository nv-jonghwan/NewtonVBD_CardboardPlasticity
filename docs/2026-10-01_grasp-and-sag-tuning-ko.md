# 초기 처짐·집기·상승 응답 튜닝 — 사용자 형태 평가로 제외

**현재 상태: 사용자가 종이박스 형태가 크게 달라졌다고 평가하여 이 후보를 제외하고 기본 GUI를 튜닝 전 장면으로 복원했다. 아래 수치 검사는 목표 처짐·간격만 확인하며 외형 보존의 충분한 검증이 아니었다. 이 문서는 실패한 시험 기록이다.**

당시 사용자 목표인 **집기 전 약 1 mm 처짐, 집기·상승 중 기존의 약 절반 접힘, 마지막 압착량 유지**에 맞춰 기본 primitive GUI 설정을 변경했다. 물리 메시의 변형을 조정했으며, 표시 표면을 보정하거나 시간에 따라 재료 강성을 바꾸지는 않는다.

## 제외한 후보의 측정

동일한 물리 메시의 윗면 중앙 25개 정점과 테두리 96개에 맞춘 평면 사이의 거리를 사용한다. 수치는 실제 셸 변형이며 상자의 상승 이동을 제거한 값이다. 기존 비교는 `outputs/vbd_optimized/guarded_b`, 새 설정은 `outputs/grasp_tuning/balanced/run` 및 `repeat`다. 새 설정 두 번 모두 16초 전 과정을 완료했다.

| 구간 | 기존 | 새 설정 두 실행 |
|---|---:|---:|
| 초기 안정 구간, 2초 | 14.48 mm | 0.938–0.941 mm |
| 집기 직전, 5초 | 14.52 mm | 1.253–1.255 mm |
| 집기 종료, 7초 | 24.18 mm | 11.409–11.416 mm |
| 상승 중, 8초 | 36.99 mm | 17.88–18.15 mm |
| 상승 종료, 9초 | 33.05 mm | 19.41–19.81 mm |
| 압착 종료, 12초 | 69.17 mm | 65.53–72.99 mm |
| 압착 종료 실제 손가락 간격 | 147.2 mm 근처 | 151.98–152.70 mm |

집기 종료와 상승 중 변형은 기존의 약 47%, 48–49%, 상승 종료는 59–60%다. 압착 종료의 중앙 접힘 깊이는 기존 대비 약 ±6% 안에 들어온다. 세부 주름 위치와 전체 소성 응답까지 동일한 것은 아니다. 새 설정은 더 많은 작은 주름을 만들며 최종 소성 힌지 수는 5,685–6,213개다. 따라서 기존 압착의 **거시적 깊이와 닫힘 간격을 비슷하게 맞춘 결과**로 해석해야 한다.

## 제외한 후보에 사용했던 설정

고정된 재료값으로 작은 하중에 강하게 버티고, 항복 후에는 국부 주름이 연화되도록 조정했다. 두께·면밀도·막 강성·마찰·메시·충돌체는 그대로다.

| 항목 | 기존 | 튜닝 |
|---|---:|---:|
| 기준 굽힘 MD / CD | 0.55556 / 0.27778 | 8.88889 / 4.44444, 16배 |
| 항복곡률 | 6 | 0.375 |
| 경화비 | 0.01 | 0.000625 |
| 손상률 | 4 | 400 |
| 잔류 강성 비율 | 0.18 | 0.01125 |
| 집기 구동 기준 | 250 N | 750 N |
| 상승 유지 구동 기준 | 집기와 동일 | 200 N |
| 압착 구동 기준 | 4,000 N | 6,000 N |
| 집기 닫힘 ramp fraction | 0.7 | 0.5 |
| 강체별 입자 접촉 저장 용량 | 256 | 512 |
| 관절 구조 선형 강성 | 100,000 N/m | 200,000 N/m |

초기 굽힘 강성을 16배로 올리면서 항복곡률과 경화비를 1/16로 줄여 **초기 항복 모멘트와 초기 경화 계수**를 유지했다. 잔류 강성 비율도 1/16로 줄여 완전히 손상된 힌지의 절대 탄성 강성 하한을 유지했다. 손상 이후 항복 모멘트 및 소성 일까지 기존과 같다는 뜻은 아니다. 실제 소성 일과 주름 분포는 달라진다. 재료 실험으로 식별한 값이 아니라 요청된 데모 응답에 맞춘 값이다.

초기 강성만 높인 후보는 집기와 압착 모두 지나치게 단단해져 제외했다. 손상률 80/400, 집기 힘 및 상승 힘, 닫힘 시간 후보를 비교한 뒤 위 설정을 선택했다. 강성이 높은 새 판을 집기 때문에 입력 힘 기준은 증가했지만, 측정한 윗면 변형은 감소했다. 이 값들은 암시적 관절 스프링의 구동 기준이며 실제 접촉력의 엄격한 상한은 아니다.

새 `liftForce`는 0이면 기존처럼 `graspForce`를 그대로 사용한다. 양수이면 상승 시작 후 첫 0.5초 동안 750→200 N을 5차 보간으로 부드럽게 전환한다. 압착은 직전 유지값 200 N에서 6,000 N으로 연속적으로 연결한다. `liftForceRampFraction` 기본값은 0.25다. 기존 장면은 새 필드 기본값으로 원래 힘 명령을 보존한다.

초기 후보의 강한 압착에서 한 강체의 접촉 수가 256개를 초과했다. 이 후보들은 최종 결과로 사용하지 않았다. 저장 용량을 512로 늘린 최종 두 실행에는 접촉 overflow 경고가 없다. 추가 반복 계산 예산을 늘린 것이 아니라 접촉 목록이 잘리는 것을 막았다. 관절 구조 강성 보강은 압착 중 연결점 오차를 2 mm 아래로 유지하기 위한 것으로, 최종 최대 오차는 1.484 / 1.280 mm다.

## 검증과 남은 한계

- 55개 회귀 검사 통과. 새 힘 전환의 경계 연속성, 기존 명령 보존, 256개를 넘는 접촉에 대한 원본 커널과 최적화 커널의 정확한 출력 일치를 포함한다.
- 배포용 USD는 선언한 12개 재료·구동·용량 필드만 변경했다. 시험 장면과 모든 속성 값이 일치하고 원본 장면 SHA 및 모든 다른 속성·관계·prim 경로를 보존했다.
- 두 실행 모두 목표 변형 검사 11개 통과, 집기 전 소성 없음, 양손 접촉 상승, 압착, 해제, 테이블 착지, 관절 연결 검사 통과. 박스 상승량은 179.9 / 184.1 mm다.
- 기존 시나리오 검사 결과는 14/15 및 15/15다. 첫 실행은 최종 최대 속도 57.8 mm/s로 `settled <10 mm/s`를 통과하지 못했다. 두 번째는 7.63 mm/s로 통과했다. **낙하 후 완전 정착의 반복성은 여전히 해결되지 않았다.** 통과 기준을 낮추거나 이 실패를 숨기지 않았다.
- 기본 설정으로 Isaac GUI Play→Pause 유지→Reset→Play, 0.25초 완료 및 정상 종료를 확인했다. 이후 데스크톱 GUI를 새 장면으로 다시 열었다.

계산 해상도 3,458 정점/6,912 삼각형, active 16 substeps 및 48회 rigid 반복/17회 shell sweep, supported 32 substeps/48회 sweep과 guarded 최적화를 유지했다. GPU 1 전체 실행은 **197.40초**, 이전 동일 GPU의 guarded 중앙값은 191.56초다. 단일 관측으로 약 3% 차이며 동일한 속도나 추가 가속을 보장하는 통계적 비교는 아니다. GPU 0 반복은 293.48초였으나 도중 다른 프로젝트의 GPU 작업이 시작되어 성능 비교에 사용하지 않는다. 해당 프로세스는 변경하지 않았다.

## GUI 사용 및 되돌리기

기본 primitive 실행은 **튜닝 전 장면과 기존 기록 재생**을 선택한다. 계산 속도 개선용 guarded 스케줄은 유지한다. 제외 후보의 1 mm/절반 처짐 수치는 현재 기본 설정에 적용되지 않는다.

```bash
./scripts/python.sh scripts/live_isaac.py --quality robotiq-primitive
```

기존 장면은 보존되어 있으며 다음처럼 명시적으로 열 수 있다.

```bash
./scripts/python.sh scripts/live_isaac.py --quality robotiq-primitive \
  --scene assets/demo_scene_robotiq_board10_primitive.usda \
  --replay-directory outputs/vbd_optimized/guarded_b
```

제외하여 보관한 시험 장면: `assets/demo_scene_robotiq_board10_grasp_tuned.usda` (기본 실행에서 사용하지 않음). 구현: `src/cardboard/scenario.py`, `simulation.py`, 스키마 기본값. 재현: `build_grasp_tuning.py`, `benchmark_vbd_optimized.py --panel-diagnostics`, `measure_grasp_tuning.py`, `review_grasp_tuning.py`, `validate_grasp_tuning_asset.py`. 원시 기록과 실패 후보는 `outputs/grasp_tuning/`에 보존했다.


## 사용자 평가 후 복구 검증

GUI PID 117317에서 원래 primitive 장면으로 16초 전체 실행 완료를 확인했다. 물리 정점 3,458개와 강체 17개의 좌표는 모두 유한하며 Newton 1.6.0 / guarded 스케줄을 사용했다. 최종 소성 힌지 3,372개로 기존 기록 3,357개에 가깝지만, 이것만으로 시각적 동등성을 보장하지 않는다. 제외 후보는 5,685–6,213개였다. 원본 USD 해시는 이전 기록과 동일하다. 사용자가 보고 있는 창은 유지했다.

이번 실패는 처짐 깊이와 손가락 간격만으로 재료 응답 보존을 판단할 수 없음을 보여 준다. 다음 후보의 필수 조건은 기존 판면과 주름 분포 보존이며, 기존 항복·손상·압착 설정을 크게 바꾸는 접근은 제외한다. 작은 변형에서의 보강을 별도 검토할 수 있으나 아직 구현하거나 검증하지 않았다. **현재 복구본은 초기 1 mm/집기 절반 목표를 달성한 새 튜닝 결과가 아니다.**
