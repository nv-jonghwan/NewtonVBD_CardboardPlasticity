# 대표 요소 ROM과 접촉·주름 국부 보정 구현

이전 교대 프로토타입에 대표 요소 적분과 GPU 국부 패치 보정을 추가했다. 4mm 비균일 격자(1,402정점/2,800삼각형/4,200힌지), 8개 ROM 기저, 24회 반복을 사용한다. 기존 기본 장면과 기본 솔버는 교체하지 않았다. 아래 후보는 명시적인 실행 설정으로 선택한다.

## 실제 실행 구조

한 서브스텝 안에서 ROM과 VBD 보정 자리를 번갈아 배치한다. 24회 중 ROM12회, VBD 보정12회이며 기본 감사 주기8에서는 후자의9회가 국부 보정,3회가 전체 색상 순차 VBD이다. 마지막 반복은 항상 전체 VBD이다. 24회 사이에 물리 시간이 따로 흐르거나 접촉 프레임을 건너뛰지 않는다. 강체/관절 반복, 전체 충돌 탐색과 충돌 절단, 전체 힌지 소성 이력 갱신은 유지한다.

**대표 요소 ROM:** 면 방향·공간 위치별로 대표 삼각형/힌지를 고르고, 각 대표가 담당하는 원래 면적/길이에 비례하는 양의 가중치를 사용한다. 모서리의 초기 접힘 힌지는 모두 평가한다. 25% 설정은 삼각형700/2,800, 힌지1,192/4,200개이다. 선택된 요소의 모든 코너 힘을 계산하므로 내부 힘의 상쇄를 유지한다. 관성·접촉력은 샘플링하지 않는다. 이는 공간 적분 규칙이며 학습 최적화된 cubature나 정확한 전체 Galerkin 축소를 구현했다고 주장하지 않는다. 작은 계수계는 기존 `Uᵀ D U` 투영 준뉴턴 방식이다.

**국부 패치:** GPU가 실제 접촉에 가까운 입자/모서리/삼각형과 이미 소성 변형되거나 곡률이 큰 힌지를 찾는다. 접촉 여유2mm와 위상 이웃1단계를 포함한다. 이웃에는 굽힘 요소의 반대편 정점도 포함한다. 실제 거리 검사를 도입하기 전 후보는 먼 충돌 후보까지 표시해 패치가 불필요하게 커졌으므로 최종 후보로 선택하지 않았다.

패치의 각 정점에서는 연결된 **전체 요소의 원래 재질**로 보정한다. 선택되지 않은 정점의 탄성 업데이트를 생략해도 기존 ROM 변위를 0으로 지우지 않는다. 충돌 절단과 전역 강체 모드 보정은 전체 상태에 작용하므로 패치 밖 정점이 절대로 움직이지 않는다는 의미는 아니다.

국부 계산에는 두 옵션이 있다.

- `colored`: 기존 색상 순차 갱신을 유지하며 비활성 정점 계산만 생략한다.
- `jacobi`: 같은 고정 위치에서 활성 정점별 보정을 동시에 구하고 0.5배 감쇠해 적용한다. **감쇠 블록 Jacobi 변형**으로, 원래 색상 Gauss–Seidel과 같은 알고리즘은 아니다. 별도 옵션으로 유지한다.

Jacobi 옵션은 국부 보정9회를 각각8색상이 아닌1개 병렬 묶음으로 실행한다. 서브스텝당 색상 묶음은 기존96개에서33개(전체3×8 + 국부9×1)로 감소한다. 전체 솔버 실행 시간이 그 비율만큼 줄어든다는 뜻은 아니다.

## 압착에서의 샘플링 대응

전체 요소와 대표 요소를 **동일한 고정 위치/원래 재질/관성 입력**에서 비교했다. 이 검사는 접촉과 실제 소성 이력을 재현한 궤적 정확도 검사가 아니라 내부 힘 적분만 분리한 검사이다. 25% 대표 요소의 ROM 투영 힘 상대 차이는5초 위치6.7%,9초11.2%,12초 약39.6%로 커졌다.

따라서 검토 후보에는 `--rom-full-after-yield`를 켰다. 누적 소성 각도1e-4rad를 넘는 힌지가 나타나면 GPU에서 전체 요소 적분으로 전환한다. 기저를 교체하거나 과거 위치를 재생하지 않는다. 실제 후보는 약6.067초부터 전체 요소를 평가했다. 현재 전환 기준은 보수적인 전역 기준이며, 요소별 적응 quadrature는 구현하지 않았다.

전체 요소 평가도 정점별 인접 요소 순회에서 **요소별 코너 병렬 계산·합산**으로 바꿨다. 이것이 샘플링을 끈 뒤에도 유지되는 개선이다. 최종 고정 입력 GPU 계측:

| 위치 샘플 | 기존 전체 요소 순회 | 새 전체 요소 합산 | 25% 대표 요소 |
|---|---:|---:|---:|
| 5초 | 0.0648ms | 0.0193ms | 0.0168ms |
| 9초 | 0.0515ms | 0.0193ms | 0.0161ms |
| 12초 | 0.0517ms | 0.0193ms | 0.0161ms |

각 값은50회 GPU Graph 반복을5번 측정한 중앙값이다. 초기화/JIT와 전체 시뮬레이션 시간은 제외했다. 이 작은 격자에서는25%→12.5%로 더 줄여도 거의 빨라지지 않았다. 주된 개선은 요소별 작업 분배와 국부 병렬 보정이며, 샘플 수 감소만의 효과로 해석하면 안 된다. [원시 계측](../outputs/local_rom/element_profile_final/report.json).

## 전체 동작 관측

| 실행 | 16초 계산 시간 | 상승 | 최종 최대 정점 속도 |
|---|---:|---:|---:|
| 전체 요소·전체 VBD 교대 기준, 첫 실행 | 204.78초 | 153.93mm | 157.86mm/s |
| 같은 기준 재실행 | 139.46초 | 153.55mm | 616.20mm/s |
| 고정25%·국부 Jacobi | 126.83초 | 153.36mm | 79.66mm/s |
| 고정25%·국부 colored | 94.48초 | 151.21mm | 519.49mm/s |
| 항복 대응25%→전체·국부 Jacobi | **82.85초** | **153.40mm** | **73.84mm/s** |

모두 동일 GPU1에서 순차 실행했지만, 다른 프로젝트의 GPU 작업이 실행/교체되는 동안 측정되어 부하가 일정하지 않았다. 같은 기준204.78→139.46초 차이부터 환경 변동을 보여 준다. 후보82.85초와 재측정 기준139.46초는 약40.6% 시간 감소 **관측**이며 재현 가능한 확정 가속비가 아니다. 안착 모드의 프레임 수도 다르다. 동일 입력의 작은 커널 계측과 전체 시퀀스 관측을 구분한다.

항복 대응 후보는 집기·상승·압착·분리·옆면 낙하를 수행했고 기존15개 동작 지표 중14개를 통과했다. 안착 속도 기준10mm/s는 통과하지 못했다. 소성 이력 유효성, 손상 범위, 비음수·단조 소성 일, 하중 중 수면 없음은 통과했다.

국부 패치는 집기 단계 평균60.8%, 상승50.98%, 압착83.4%, 낙하 후 거의100%의 정점을 포함했다. 후반에는 주름과 접촉이 박스 전체로 확장되어 작은 영역만 계산하는 이점이 줄어든다. 이때에도 병렬 묶음과 요소별 적분의 이점은 남는다.

기준 재실행 대비 강체 정렬 형상 RMS는7초2.19mm,9초1.35mm이나12초46.49mm,16초52.06mm이다. 기준을 반복한 두 궤적끼리도12초37.52mm,16초48.17mm 차이가 났다. 따라서 후보가 기존 압착 형상을 보존한다고 주장할 수 없고, 반복 수/접촉 경로의 민감도와 기준 자체의 수렴 문제도 분리해야 한다. 종이박스 모양과 안착의 최종 승격은 여전히 열려 있다.

학습에 없는 조건도 같은 기저로 시험했다. 상승 명령200→180mm, 압착 간격140→150mm, 압착 힘4000→3600N으로 변경했다. 후보는133.44mm 상승, 기준은133.69mm 상승했고 둘 다14/15 동작 지표(안착 실패)를 기록했다. 최종 속도는 후보125.96mm/s, 기준198.14mm/s였다. 후보131.64초/기준110.10초로 이 조건에서는 가속을 확인하지 못했다. 공유 GPU 부하와 동작/안착 경로 차이가 있어 일반적인 속도 향상으로 결론 내리지 않는다.

기본·추가 조건 후보 모두 조기 바닥 복귀 없이 양측 접촉을 유지했으나, 압착까지 포함한 패드 상대 이동20mm 기준은 실패했다. 집기 성공과 무슬립은 다른 지표이다. 추가 조건의 형상 RMS도9초1.55mm에서12초37.87mm로 증가했다. [추가 조건 비교](../outputs/local_rom/heldout_review/summary.json), [추가 조건 이력 검사](../outputs/local_rom/heldout_rest_review.json). 모든8개 전체 궤적 실행에서 충돌 버퍼 초과나 실행 예외 로그는 없었다.

## 검증과 실행

최종79개 회귀 검사 통과. 대표 요소 가중치의 양수/영역별 적분량, 전체 요소 선택 시 원래 힘/Hessian과 수치 일치, 내부 힘 평형, 항복 전후 GPU 전환, 접촉 거리·양쪽 접촉 참여자·위상 확장, 비활성 정점 변위 보존, Jacobi의 고정 위치 블록 업데이트, guarded 거절 시 전체 VBD 복귀를 검사했다. 재질 S16 및 소성 이력을 두 경로가 동일하게 사용한다.

GUI에 `--solver-config`를 추가해 검증한 benchmark 설정을 워커로 전달한다. headless Play/Pause/Reset 검사를 통과했고, 리셋 후에도 Newton1.6/24회/대표 요소/국부 Jacobi/항복 전환 설정을 확인했다. [GUI 검증](../outputs/local_rom/gui_verification.json). 데스크톱 GUI를 자동으로 열거나 기존 기본값으로 승격하지 않았다.

```bash
# 새 물리 계산
OPENBLAS_NUM_THREADS=1 ./scripts/python.sh scripts/benchmark_vbd_optimized.py \
  --scene assets/demo_scene_robotiq_board4_graded.usda --output outputs/local_rom/my_run \
  --schedule guarded --device cuda:1 --iterations 24 --panel-diagnostics --exploratory \
  --small-bend-scale 16 --small-bend-knee .75 --small-bend-end 14.75 \
  --rom-basis outputs/graded_board4/basis8.npz --rom-tolerance 1 --rom-start --rom-fast \
  --rom-element-fraction .25 --rom-full-after-yield --local-vbd --patch-solver jacobi

# 동일 설정의 명시적 GUI 미리보기
./scripts/python.sh scripts/live_isaac.py --quality robotiq-primitive --physics-device cuda:0 \
  --scene assets/demo_scene_robotiq_board4_graded.usda \
  --solver-config outputs/local_rom/adaptive_jacobi24/run_config.json \
  --replay-directory outputs/local_rom/adaptive_jacobi24 \
  --small-bend-scale 16 --small-bend-knee .75 --small-bend-end 14.75
```

접촉·ROM·패치 선정·항복 전환·전체 보정은 CUDA Graph 안에서 GPU로 실행한다. CPU의 프레임 제어·정지 판단·진단·GUI 전달은 이전과 같이 남아 있다. 대표 요소나 패치 선택을 위해 매 반복 CPU로 왕복하지 않는다.

설계 참고: 대표 요소 적분은 [Optimizing Cubature](https://doi.org/10.1145/1409060.1409118)의 문제 설정, 국부 full-space 보정은 [Subspace Condensation](https://www.tkim.graphics/CONDENSE/)의 적응 공간 아이디어를 참고했다. 논문의 최적화/condensation 알고리즘을 그대로 구현한 것은 아니다.
